# v8 引擎是怎么工作的
1. 分词
2. 语法分析 得到 AST 树
3. 代码生成

# 预编译
编译发生在代码执行之前

# 函数体内的预编译
1. 创建一个执行上下文对象 AO:{}
2. 找形参和变量声明，将形参和变量名作为属性名，添加到 AO 中，值为 undefined
3. 将形参和实参统一
4. 在函数体内找函数声明，将函数名作为 AO中的属性名，函数体作为属性值

# 全局的预编译
1. 创建全局执行上下文对象 GO:{}
2. 找全局变量声明，将全局变量名作为属性名，添加到 GO 中，值为 undefined
3. 找全局函数声明，将函数名作为GO 的属性名，函数体作为属性值
