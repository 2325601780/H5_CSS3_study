# 异步
1. 能按顺序从上往下依次执行（同步）
2. 在执行的过程中，如果遇到一个耗时的任务，就分精力出来执行另一个任务（异步执行）


- js 默认是单线程执行的
1. 线程：CPU 执行指令所需要的时间
2. 进程：CPU 接收到一个指令，到加载完上下文所需要的时间

举例：在浏览器上新开一个 tab 页，称之为开启了一个新的进程，而这个进程中是有很多个线程通力合作的（HTTP 网络线程，页面渲染线程）

启用 v8 来运行 js 这可以称之为一个进程，但是 v8 默认只会开启一个线程来执行代码，所以遇到耗时的任务，会先将它挂起，先去执行不耗时的任务


# 回调
当 B 函数需要依赖异步 A 的结果，我们将 B 函数的调用放在 A 里面

回调地狱：当程序繁重，排查问题的难度大，可读性差
