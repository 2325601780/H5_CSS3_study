# js 的执行
1. v8 会读取代码，并不会第一时间执行，而是要先编译（梳理）
2. 分词：将代码拆分成一个一个的词法单元
3. 解析/语法分析：将词法单元组织成一个抽象语法树 AST（Abstract Syntax Tree）
4. 执行：根据 AST 生成代码并执行

# 作用域
1. 全局作用域
2. 函数作用域
3. 块级作用域

在 v8 的执行过程中，查找一个变量时，会现在当前作用域查找，如果找不到，就会去外层作用域中查找，直到找到全局作用域，还是找不到，就会报错。

# let, const
1. let + {} 会形成块级作用域
2. let 不会带来声明提升
3. const 声明的是常量，不能重新赋值
