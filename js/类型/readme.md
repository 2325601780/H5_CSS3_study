# v8执行的过程
1. 创建一个调用栈 （用来存放预编译的过程）
2. 在调用栈中，存入 xx 执行上下文
3. 执行代码，将原始值存入栈中，如果遇到引用类型的值，则将值存入堆空间并生成一个引用地址，将引用地址存入栈中，这样设计的好处，即保证了栈不用设计的很大从而影响 v8 的执行效率，又不会爆栈
