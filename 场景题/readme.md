# 图片懒加载
  - 一个页面上的图片资源过多，初次加载时会占用较多的带宽和时间，导致页面加载缓慢。所以我们可以使用懒加载技术，只有当图片进入视口时，才加载图片资源。

  1. 通过getBoundingClientRect()方法获取图片的坐标信息,判断图片是否进入视口。
  2. 使用 IntersectionObserver 监听图片进入视口事件。
