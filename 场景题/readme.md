# 图片懒加载
  - 一个页面上的图片资源过多，初次加载时会占用较多的带宽和时间，导致页面加载缓慢。所以我们可以使用懒加载技术，只有当图片进入视口时，才加载图片资源。

  1. 通过getBoundingClientRect()方法获取图片的坐标信息,判断图片是否进入视口。
  2. 使用 IntersectionObserver 监听图片进入视口事件。

# 跨域
  - 同源策略
    一个url的样子： https://192.168.0.1:3000/user
                   协议 + 域名 +        端口 路径
    同源策略：协议、域名、端口必须相同（旨在保护后端数据安全）    源不一致的设备不能随便访问

    1. jsonp: 借助script标签的src不受同源策略限制的原理，将请求放在src上发出，并给后端传递一个固定参数cb，在window上定义一个cb函数，当前端向后端发送请求时,后端接到请求时，会向前端响应数据，将数据作为cb函数的调用形式中的实参返回，导致window上的cb函数触发。
    
      - 缺点：
        1. 只能发送get请求
        2. 必须要后端配合

    2. cors: 后端配置响应头 Access-Control-Allow-Origin 的白名单，那么白名单中的域名才能跨域请求。

    3. proxy: 代理服务器
      前端向代理服务器发送请求，代理服务器向后端发送请求，后端返回数据给代理服务器，代理服务器再将数据返回给前端。

    4. nginx: 反向代理
      前端向nginx发送请求，nginx向后端发送请求，后端返回数据给nginx，nginx再将数据返回给前端。

    5. websocket: socket天生不受同源策略限制，可以跨域请求。

    6. postMessage: window.postMessage() 方法可以实现不同窗口父子页面之间的跨域通信。

# 大文件上传
1. 用户选中一个大文件
2. 前端将大文件切片成多个小文件（文件切片）
3. 前端将每个小文件上传给后端
4. 后端将所有小文件合并成大文件
5. 后端保存大文件到服务器
